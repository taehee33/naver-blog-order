# 사진 방향 추천(AI) 자동 테스트

네이버 글쓰기 화면을 흉내 낸 목업(`mock-*.html`)에 확장을 붙여 다음을 확인한다.

1. 설정 창에서 가벼운 모드를 고르면 모델 설치가 끝나 "설치됨"으로 바뀌는지
2. 사진 6장을 올리면 정렬과 AI 분석이 되고, 누운 사진(10·12·28·33)에 회전 추천이 붙는지
3. [네이버 편집기로 N장 돌리기]를 누르면 편집기 썸네일 → 자르기·회전 → 왼쪽 회전 → 적용이 눌리는지
   - 기존 사진과 바로 선 사진(03·30)은 돌리지 않는지
   - [완료]는 누르지 않는지

## 실행 방법

- 테스트용 확장 사본의 `ai-config.js` URL을 `http://localhost:8765/`로 바꾼다.
- `models/`에 `orientation-int8.onnx`를, `imgs/`에 테스트 사진을 넣는다.
- `python3 server.py &`로 모델 서버를 띄운다.
- `EXT=<테스트용 확장 경로> node run.js`로 실행한다.
- 옵션 환경변수
  - `SKIP28=1`: 28번을 제외했을 때 3장만 도는지 확인
  - `AIOFF=1`: AI를 껐을 때 AI 영역이 안 뜨는지 확인

2026-10-22 결과: 세 경우 모두 통과했다. 분석은 6장에 약 7초(모델 로딩 포함)가 걸렸다.
