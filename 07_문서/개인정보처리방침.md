# 개인정보처리방침 — 네이버 블로그 사진(파일) 업로드 순서 유지

**네이버 블로그 사진(파일) 업로드 순서 유지** 확장 프로그램은 사용자의 개인정보를 수집, 저장, 전송하지 않습니다.

- **수집하는 정보**: 없음
- **파일 처리**: 사용자가 업로드하려고 선택한 파일의 이름·크기·수정일·종류, 그리고 사진의 촬영일(EXIF, JPEG·HEIC·PNG)을 정렬과 결과 목록의 썸네일 표시 목적으로만 브라우저 안에서 읽습니다. 파일 내용이나 정보를 외부 서버로 보내지 않습니다.
- **사진 방향 추천(AI)**: 켠 경우에만 사진을 384×384로 줄인 픽셀로 확장 프로그램 안의 AI 모델이 방향을 판단합니다. 분석은 사용자 컴퓨터 안에서만 이루어지고 사진은 전송되지 않습니다. 회전은 네이버 에디터의 「사진 편집 → 자르기, 회전」 기능을 사용하며, 원본 파일은 수정하지 않습니다.
- **저장하는 정보**: 정렬 설정(사용 여부, 정렬 기준, 순서, 알림·결과 목록·썸네일 표시 여부)과 AI 모드만 크롬의 `chrome.storage.sync`에 저장합니다. 크롬 동기화가 켜져 있으면 사용자의 구글 계정을 통해 다른 기기의 크롬과 동기화될 수 있습니다.
- **AI 모델 저장**: AI를 켜면 모델 파일(약 21~40MB)과 설치 상태를 확장 전용 저장 공간(Cache Storage, `chrome.storage.local`)에 저장합니다. 설정 창의 [모델 삭제]로 지울 수 있습니다.
- **외부 통신**: AI를 켠 경우에만 모델 파일을 `taehee33.github.io`에서 한 번 내려받습니다(사진·개인정보 미포함). 원격 코드를 불러오지 않습니다(실행 엔진 onnxruntime-web은 확장에 포함, 모델 파일은 데이터).
- **권한**: `storage`(설정), `offscreen`(AI 실행용 숨은 확장 페이지), `unlimitedStorage`(모델 파일 저장)
