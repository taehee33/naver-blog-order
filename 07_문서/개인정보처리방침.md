# 개인정보처리방침 — 네이버 블로그 파일 순서 유지

**네이버 블로그 파일 순서 유지** 확장 프로그램은 사용자의 개인정보를 수집, 저장, 전송하지 않습니다.

- **수집하는 정보**: 없음
- **파일 처리**: 사용자가 업로드하려고 선택한 파일의 이름·크기·수정일·종류, 그리고 사진의 촬영일(EXIF, JPEG·HEIC·PNG)을 정렬과 결과 목록의 썸네일 표시 목적으로만 브라우저 안에서 읽습니다. 파일 내용이나 정보를 외부 서버로 보내지 않습니다.
- **저장하는 정보**: 정렬 설정(사용 여부, 정렬 기준, 순서, 알림·결과 목록·썸네일 표시 여부)만 크롬의 `chrome.storage.sync`에 저장합니다. 크롬 동기화가 켜져 있으면 사용자의 구글 계정을 통해 다른 기기의 크롬과 동기화될 수 있습니다.
- **외부 통신**: 없음. 원격 코드를 불러오지 않습니다.
- **제3자 제공**: 없음
