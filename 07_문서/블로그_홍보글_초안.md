# 블로그 홍보글 초안

> [스토어 링크]는 심사 승인 후 채우기. 이미지 파일명은 03_스토어_이미지 / 04_실제사용_스크린샷 폴더 기준.

## 제목 후보

- 블로그에 사진 올릴 때 순서 뒤섞이는 분들, 이거 써 보세요 (직접 만든 크롬 확장)
- 네이버 블로그 사진 순서, 이제 파일명 순서 그대로 올라가요
- 사진 순서 맞추느라 드래그하던 시간, 0초로 줄였습니다

## 본문

안녕하세요, 태희입니다 :)

블로그에 여행 사진 올려 보신 분들은 다 아실 거예요.
폴더에서 1번부터 30번까지 예쁘게 정리해 놨는데, 한 번에 올리면 순서가 뒤죽박죽 섞여서 들어가는 거요.
결국 사진을 하나하나 끌어서 다시 맞추다 보면 글 쓰는 시간보다 사진 정리하는 시간이 더 길어지더라고요.

그래서 직접 만들었습니다.
**'네이버 블로그 파일 순서 유지'** 크롬 확장 프로그램이에요.

[이미지: screenshot-1-main.png]

### 이런 걸 해 줘요

사진을 여러 장 선택하거나 끌어다 놓으면, 에디터에 들어가기 직전에 순서를 정리해 줘요.

- **파일명 순** (기본) : IMG_2 다음에 IMG_10이 오도록 숫자도 똑똑하게 인식해요
- **수정한 날짜 순**
- **촬영일 순** : 사진 안에 저장된 촬영 시간(EXIF)을 읽어요. 아이폰 사진(HEIC)도 돼요
- **크기 순 / 종류 순**
- 전부 **오름차순 · 내림차순** 선택 가능
- 파일 선택, 끌어다 놓기는 물론 **폴더째 끌어다 놓기**도 정렬돼요

[이미지: screenshot-2-before-after.png]

### 실제로 써 봤어요

요즘 찍고 있는 필름 사진으로 바로 테스트해 봤어요.
스캔 받은 파일이 `4771_01.jpg`부터 순서대로 있는 폴더예요.

[이미지: real-1-folder-masked.png]

이 사진들을 한 번에 올렸더니, 화면 아래에 이렇게 알림이 떠요.

[이미지: real-3-toast.png]

그리고 에디터에도, 오른쪽 라이브러리에도 폴더에서 보던 순서 그대로 들어갔어요. 사진 39장을 하나도 안 옮기고 바로 글을 쓸 수 있었어요 👍

[이미지: real-2-editor.jpg]

### 쓰는 법

1. 크롬 웹스토어에서 설치 → **[스토어 링크]**
2. 오른쪽 위 퍼즐 아이콘에서 핀 고정
3. 아이콘을 눌러 정렬 기준만 골라 두면 끝!

[이미지: screenshot-3-settings.png]

### 정렬 결과도 바로 확인

사진을 올리면 화면 오른쪽에 **어떤 순서로 정리됐는지 목록**이 쭉 떠요.
사진 썸네일과 파일 이름, 기준값(촬영일·날짜 등)이 함께 보여서 순서를 한눈에 확인할 수 있어요.
× 버튼으로 닫으면 되고, 거슬리면 "다음부터 자동으로 열지 않기"를 체크하세요. 설정 창의 "최근 정렬 결과 보기"로 언제든 다시 볼 수 있어요.

[이미지: screenshot-4-panel.png]

이후엔 평소처럼 블로그 글쓰기에서 사진을 올리시면 돼요.
정렬이 되면 화면 아래에 **'네이버 블로그 파일 순서 유지: 파일 N개를 파일명 오름차순으로 정리했어요'** 알림이 떠서 바로 확인할 수 있어요.

### 개인정보는요?

아무것도 수집하지 않아요.
파일 이름·날짜 같은 정보는 정렬할 때 내 브라우저 안에서만 잠깐 읽고, 어디로도 보내지 않아요. 저장하는 건 '어떤 기준으로 정렬할지' 설정뿐이에요.

### 참고해 주세요

- 촬영일 정보가 없는 사진(스크린샷 등)은 수정한 날짜 기준으로 정렬돼요.
- 네이버 공식 도구가 아니라 제가 개인적으로 만든 확장이에요. 네이버 에디터가 바뀌면 동작이 달라질 수 있는데, 그때그때 업데이트할게요.

불편한 점이나 "이런 기능도 있으면 좋겠다" 싶은 건 댓글로 남겨 주세요.
사진 순서 맞추는 시간 아껴서, 그 시간에 글 한 줄 더 쓰시길 바라요 :)
