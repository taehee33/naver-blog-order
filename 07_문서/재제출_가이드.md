# 웹스토어 재제출 가이드 (v1.2.0)

1. 항목 페이지 오른쪽 위 ⋮ → **검토 취소** (상태가 "초안"으로 돌아옴)
2. **패키지 → 새 패키지 업로드** → `02_스토어_업로드/webstore-upload_v1.2.0.zip`
3. **스토어 등록정보**
   - 설명: `스토어_등록정보.md`의 설명 블록으로 통째로 교체
   - 캡처화면 순서: screenshot-0-real → screenshot-4-panel → screenshot-1-main → screenshot-2-before-after → screenshot-3-settings (3·4번은 새 파일로 교체/추가)
4. **개인정보 보호** → storage 권한 사유만 교체
   > 사용자가 선택한 정렬 기준, 정렬 순서, 알림·결과 목록·썸네일 표시 여부 설정을 저장하기 위해 사용합니다. 그 외의 데이터는 저장하지 않습니다.
5. **임시저장** → **제출하여 검토받기**

## 제출 전 확인
- [ ] `chrome://extensions`에서 새로고침 후 실제 네이버에서 사진 여러 장 업로드
- [ ] 오른쪽 결과 목록에 썸네일이 뜨는지, 업로드가 느려지지 않는지
- [ ] 끌어다 놓기 / 폴더째 끌어다 놓기 / 아이폰(HEIC) 사진 한 번씩
