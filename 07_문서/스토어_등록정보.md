### 설명 (스토어 "설명" 칸에 그대로 붙여넣기)

```
폴더에서 순서대로 정리해 둔 사진, 블로그나 카페에 한 번에 올리면 뒤죽박죽 섞이죠?
세로로 찍었는데 가로로 누워서 올라간 사진, 한 장씩 찾아서 돌리기 번거롭죠?

이 확장 프로그램은 네이버 블로그·카페에 사진·파일을 올릴 때 원하는 순서대로 정렬해서 넘겨주고,
누워 있는 사진은 AI가 찾아 네이버 편집기로 바로 세워 줍니다.

■ NEW 네이버 카페 글쓰기 지원
· 블로그와 똑같이 카페 글쓰기·글 수정 화면에서도 업로드 순서를 정렬해요
· AI 회전 추천과 [네이버 편집기로 N장 돌리기]도 카페에서 그대로 쓸 수 있어요
· 카페 목록·글 읽기 화면에서는 동작하지 않아요

■ NEW 사진 방향 추천 (AI)
· 누워서 올라간 사진을 AI가 찾아 결과 목록에 "↺ 왼쪽 90°"처럼 표시해요
· [네이버 편집기로 N장 돌리기] 한 번이면 네이버 에디터의 「사진 편집 → 자르기, 회전」 기능으로 차례로 돌려요
· 결과는 편집기에서 직접 확인한 뒤 [완료]를 눌러 반영해요 (AI가 틀릴 수 있어서 마지막 확인은 사용자가)
· 확신도가 낮은 사진은 "확인 필요"로 표시하고, 추천 표시를 누르면 대상에서 뺄 수 있어요
· 필름 스캔본처럼 촬영 방향 정보(EXIF)가 없는 사진도 사진 내용을 보고 판단해요
· 일반 모드(약 40MB · 정확도 약 98%) / 가벼운 모드(약 21MB · 정확도 약 96%) 중 선택
  처음 켤 때 한 번만 내려받고, 언제든 모드를 바꾸거나 삭제할 수 있어요 (기본값: 사용 안 함)
· AI를 켜지 않았으면 결과 목록에 "회전 AI 꺼짐" 표시가 나오고, 눌러서 켜는 방법을 볼 수 있어요

■ 업로드 순서 유지
· 정렬 기준 선택: 파일명(기본) / 수정한 날짜 / 촬영일(EXIF) / 크기 / 종류
· 파일명 자연 정렬: IMG_2 → IMG_10 처럼 숫자 순서를 인식
· 촬영일 정렬: JPEG는 물론 아이폰 사진(HEIC)·PNG도 지원
· 오름차순 / 내림차순 선택
· 파일 선택 창, 끌어다 놓기, 폴더째 끌어다 놓기 모두 지원
· 정렬 결과 목록: 올린 순서가 사진 썸네일과 함께 화면 오른쪽에 바로 표시

■ 원본 파일은 그대로, 사진은 내 컴퓨터 안에서만
· 내 컴퓨터의 사진 파일은 절대 수정하지 않아요. 회전은 네이버 편집기 기능으로만 해요.
· AI 분석은 내 컴퓨터 안에서만 이루어지고, 사진을 어디로도 전송하지 않아요. AI 학습에도 쓰이지 않아요.

■ 사용 방법
1. 툴바의 확장 아이콘을 눌러 정렬 기준과 순서를 고릅니다.
   (선택) "사진 방향 추천 (AI)"에서 일반 모드 또는 가벼운 모드를 고르면 모델을 한 번 내려받아요.
2. 네이버 블로그 또는 카페 글쓰기에서 평소처럼 사진을 올립니다.
3. 오른쪽 목록에 회전 추천이 뜨면 [네이버 편집기로 N장 돌리기] → 편집기에서 확인 후 [완료]!

■ 참고
· 촬영일 정보가 없는 사진은 수정한 날짜로 정렬합니다.
· 자동 회전은 사진을 '개별사진'으로 올렸을 때 동작해요. (콜라주·슬라이드 제외)
· 사진이 많으면 네이버 편집기가 일부만 열 수 있어요. 이때는 [완료] 후 [남은 N장 돌리기]를 눌러 주세요.
· 네이버 화면이 바뀌면 자동 회전이 동작하지 않을 수 있어요. 결과 목록의 [진단 정보 복사]로 알려 주세요.
· AI 모델: DuarteBarbosa/deep-image-orientation-detection (MIT License)을 변환해 사용합니다.
· 본 확장 프로그램은 네이버의 공식 제품이 아닌 개인이 만든 도구입니다.

문의: hth33.dev@gmail.com
```

## 개인정보 보호 관행 (대시보드 "개인정보 보호" 탭)

- **단일 목적**
  네이버 블로그·카페에 여러 사진·파일을 올리는 작업을 돕습니다. 사용자가 고른 기준으로 업로드 순서를 정렬해 에디터에 전달하고, 누워 있는 사진을 찾아 네이버 에디터의 회전 기능으로 바로 세울 수 있게 합니다.
- **storage 권한**
  사용자가 선택한 정렬 기준·순서, 알림·결과 목록·썸네일 표시 여부, 사진 방향 추천(AI) 모드와 AI 모델 설치 상태를 저장합니다.
- **offscreen 권한**
  사진 방향을 판단하는 AI 모델(onnxruntime-web, WebAssembly)을 화면에 보이지 않는 확장 페이지에서 실행하기 위해 사용합니다. 사진은 사용자 컴퓨터 밖으로 나가지 않습니다.
- **unlimitedStorage 권한**
  사용자가 AI 기능을 켰을 때 내려받는 모델 파일(약 21~40MB)을 확장 전용 저장 공간(Cache Storage)에 보관하기 위해 사용합니다. 설정 창에서 언제든 삭제할 수 있습니다.
- **호스트 권한 (blog.naver.com, m.blog.naver.com, cafe.naver.com)**
  네이버 블로그·카페 글쓰기 화면에서만 동작합니다.
  - 사용자가 선택하거나 끌어다 놓은 파일 목록을 정렬합니다.
  - 정렬 결과와 회전 추천 목록을 표시합니다.
  - 사용자가 [네이버 편집기로 N장 돌리기]를 누르면 네이버 사진 편집기의 회전 버튼을 대신 누릅니다.
  - cafe.naver.com은 화면 이동이 새로고침 없이 이루어지는 구조라 사이트 단위로 등록했고, 실제 정렬은 글쓰기·글 수정 화면에서만 합니다.
  - 다른 사이트에서는 동작하지 않습니다.
- **원격 코드 사용: 아니요**
  - 실행되는 모든 코드(onnxruntime-web WASM 포함)는 확장 패키지에 들어 있습니다.
  - AI 기능을 켰을 때 내려받는 파일은 실행 코드가 아니라 모델 가중치 데이터(.onnx)입니다.
    - 출처: 개발자의 GitHub Pages, taehee33.github.io
    - SHA-256으로 검증합니다.
- **데이터 사용: 수집하는 데이터 없음**
  - 인증 항목 3개를 모두 체크합니다.
  - 파일과 사진은 정렬·분석을 위해 브라우저 안에서만 읽고, 어디로도 전송하지 않습니다.
- **개인정보처리방침 URL**: https://taehee33.github.io/naver-blog-order/privacy/ (v1.4.0 기준으로 갱신)
- **EEA 판매자 여부**: 비판매자
