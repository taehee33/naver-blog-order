### 설명

```
폴더에서 순서대로 정리해 둔 사진, 블로그에 한 번에 올리면 뒤죽박죽 섞이죠?
이 확장 프로그램은 네이버 블로그에 사진·파일을 여러 장 올릴 때, 원하는 기준으로 정렬된 순서대로 에디터에 넘겨줍니다.

■ 주요 기능
· 정렬 기준 선택: 파일명(기본) / 수정한 날짜 / 촬영일(EXIF) / 크기 / 종류
· 파일명 자연 정렬: IMG_2 → IMG_10 처럼 숫자 순서를 인식
· 촬영일 정렬: JPEG는 물론 아이폰 사진(HEIC)·PNG도 지원
· 오름차순 / 내림차순 선택
· 파일 선택 창, 끌어다 놓기, 폴더째 끌어다 놓기 모두 지원
· 정렬 결과 목록: 올린 순서가 사진 썸네일과 함께 화면 오른쪽 목록에 바로 표시 (닫기, 자동 열기 끄기 가능)
· 정렬되면 화면 하단에 알림 표시 (설정에서 끌 수 있음)

■ 사용 방법
1. 툴바의 확장 아이콘을 눌러 정렬 기준과 순서를 고릅니다.
2. 네이버 블로그 글쓰기에서 평소처럼 사진을 올리면 끝!
3. 정렬 결과를 다시 보고 싶으면 설정 창의 "최근 정렬 결과 보기"를 누르세요.

■ 개인정보
개인정보를 수집하지 않으며, 외부로 아무것도 전송하지 않습니다.
파일 이름·날짜 등은 정렬을 위해 브라우저 안에서만 읽고, 정렬 설정만 크롬 저장소에 보관합니다.

■ 참고
· 촬영일 정보가 없는 사진은 수정한 날짜로 정렬합니다.
· 본 확장 프로그램은 네이버의 공식 제품이 아닌 개인이 만든 도구입니다.

문의: hth33.dev@gmail.com
```
