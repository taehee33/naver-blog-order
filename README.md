# 네이버 블로그 파일 순서 유지 (크롬 확장)

네이버 블로그에 사진·파일을 여러 장 올릴 때, 파일명·수정한 날짜·촬영일(EXIF)·크기·종류 기준으로 정렬된 순서대로 에디터에 넘겨주는 크롬 확장 프로그램.

- 소스 최신 버전: **v1.2.0** (v1.0.1 심사 취소 후 재제출 예정)
- 개발자 계정: hth33.dev@gmail.com
- 웹스토어 항목 ID: `plppacomhopmompmahdianidmdocbcfl`
- GitHub: https://github.com/taehee33/naver-blog-order
- 개인정보처리방침: https://taehee33.github.io/naver-blog-order/privacy/

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `01_확장프로그램_소스` | 확장 프로그램 원본 코드와 아이콘. 개발자 모드에서 이 폴더를 "압축해제된 확장 프로그램 로드"로 불러오면 바로 실행 |
| `02_스토어_업로드` | 웹스토어 업로드용 zip (버전별, 최신은 v1.2.0) |
| `03_스토어_이미지` | 스토어 아이콘 128, 캡처화면 1280×800 4장, 프로모션 타일 440×280 / 1400×560 |
| `04_실제사용_스크린샷` | 실제 네이버 블로그 39장 업로드 테스트 캡처 (폴더 캡처는 경로·드라이브 마스킹본) |
| `05_디자인_제작스크립트` | 스토어 이미지·아이콘 시안을 만든 스크립트와 아이콘 시안 비교 이미지 |
| `06_테스트` | Playwright 자동 테스트 스크립트와 EXIF 테스트용 샘플 사진 |
| `07_문서` | 스토어 등록 문구, 개인정보처리방침, 블로그 홍보글 초안 |
| `docs` | GitHub Pages 사이트 (소개 페이지, `privacy/` 개인정보처리방침). 웹스토어에 등록하는 방침 URL이 여기서 나옴 |

## 소스 구조 (01_확장프로그램_소스)

| 파일 | 역할 |
|---|---|
| `manifest.json` | MV3 설정. 권한은 `storage`, 동작 사이트는 blog.naver.com / m.blog.naver.com (모든 프레임) |
| `bridge.js` | 확장 저장소(chrome.storage.sync)의 설정을 페이지에서 읽을 수 있게 `<html data-nbo-settings>`에 기록 |
| `sorter.js` | 페이지(MAIN world)에서 실행. `input.files` / `dataTransfer.files`·`items` getter를 감싸 정렬된 목록 반환, 폴더 드롭 시 `readEntries` 결과 정렬, 촬영일 기준이면 EXIF(JPEG·HEIC·PNG)를 읽는 동안 리스너 실행을 잠시 지연, 정렬 알림·결과 목록 패널 표시 |
| `popup.html`, `popup.js` | 툴바 설정 창 (사용 여부, 정렬 기준, 오름/내림차순, 결과 목록 자동 열기, 알림 표시, 최근 정렬 결과 보기) |
| `icons/` | 16·48·128px 아이콘 (B안: 번호 매긴 사진 목록) |

## 동작 원리 요약

1. 사용자가 파일을 선택하거나 끌어다 놓음
2. 네이버 에디터가 `files`를 읽는 순간 `sorter.js`가 정렬된 FileList를 대신 돌려줌
   - 파일명: `Intl.Collator('ko', { numeric: true })` 자연 정렬
   - 촬영일: JPEG EXIF DateTimeOriginal(없으면 수정일)
   - 기준 값이 같으면 파일명순
3. 화면 하단에 "네이버 블로그 파일 순서 유지: 파일 N개를 ○○ 오름차순으로 정리했어요" 알림

## 다시 빌드하기

- 스토어 업로드 zip: `01_확장프로그램_소스` 폴더 **안의 파일들**을 선택해 압축 (manifest.json이 zip 최상위)
- 업데이트 시 `manifest.json`의 `version`을 반드시 올릴 것

## 테스트 (06_테스트)

- `extension-test.js`: Playwright로 확장을 불러와 파일 선택·드롭·숨은 input·내림차순·크기·촬영일 정렬을 검증
  - 실행 전 스크립트 상단의 확장 경로(`ext`)와 샘플 사진 경로를 내 PC 경로로 바꿀 것
  - `npm i playwright` 후 `node extension-test.js`
- 실제 환경 테스트: 2026-10-18 네이버 블로그에서 필름 스캔 사진 39장 업로드 → 파일명 순서 확인 완료
