# 네이버 블로그·카페 사진(파일) 업로드 순서 유지 +회전(AI) (크롬 확장)

네이버 블로그·카페에 사진·파일을 여러 장 올릴 때, 파일명·수정한 날짜·촬영일(EXIF)·크기·종류 기준으로 정렬된 순서대로 에디터에 넘겨주는 크롬 확장 프로그램.
v1.3.0부터는 세로로 찍었는데 누워 있는 사진을 AI로 찾아 **네이버 에디터의 사진 편집 기능으로** 돌려준다(원본 파일은 건드리지 않음).
v1.4.0부터는 네이버 카페 글쓰기·글 수정 화면에서도 똑같이 동작한다.

| `bridge.js` | 확장 저장소의 설정·AI 설치 상태를 페이지에서 읽을 수 있게 `<html data-nbo-settings>`에 기록. 페이지 ↔ 백그라운드 AI 분석 요청 중계 |
| `background.js` | 서비스 워커. 오프스크린 문서를 만들고 설치·삭제·분석 요청을 전달, 설치 상태를 `chrome.storage.local.aiStatus`에 기록 |
| `offscreen.html`, `offscreen.js` | 보이지 않는 확장 페이지. 모델 다운로드(진행률·SHA-256 검증) → Cache Storage 저장, onnxruntime-web(WASM)으로 방향 분석 |
| `ai-config.js` | 모델 URL·크기·SHA-256, 확신도 기준 |
| `ort/` | onnxruntime-web 1.22.0 WASM 런타임 (확장에 포함, 원격 코드 아님) |
| `sorter.js` | 페이지(MAIN world)에서 실행. `input.files` / `dataTransfer.files`·`items` getter를 감싸 정렬된 목록 반환, 폴더 드롭 시 `readEntries` 결과 정렬, 촬영일 기준이면 EXIF(JPEG·HEIC·PNG)를 읽는 동안 리스너 실행을 잠시 지연, 정렬 알림·결과 목록 패널 표시 |
| `popup.html`, `popup.js` | 툴바 설정 창 (사용 여부, 정렬 기준, 오름/내림차순, 결과 목록 자동 열기, 알림 표시, 최근 정렬 결과 보기) |

## 동작 원리 요약

1. 사용자가 파일을 선택하거나 끌어다 놓음
2. 네이버 에디터가 `files`를 읽는 순간 `sorter.js`가 정렬된 FileList를 대신 돌려줌
   - 파일명: `Intl.Collator('ko', { numeric: true })` 자연 정렬
   - 촬영일: JPEG EXIF DateTimeOriginal(없으면 수정일)
   - 기준 값이 같으면 파일명순
3. 화면 하단에 "사진 업로드 순서 유지 +회전(AI): 파일 N개를 ○○ 오름차순으로 정리했어요" 알림

## 사진 방향 추천 (AI) — v1.3.0

원칙: **확장은 사진 파일을 한 바이트도 바꾸지 않는다.** 읽어서 판단만 하고, 회전은 네이버 에디터의 「사진 편집 → 자르기, 회전」 버튼을 대신 눌러 준다. 마지막 [완료]는 사용자가 확인 후 직접 누른다.

1. 설정 창에서 모드 선택 → 모델을 `docs/models`(GitHub Pages)에서 한 번 내려받아 저장
   - 일반 모드: `orientation-fp16.onnx` 40.4MB · 정확도 약 98%
   - 가벼운 모드: `orientation-int8.onnx` 21.0MB · 정확도 약 96%
   - 모드 변경 시 이전 모델은 지우고 새 모델 설치, [모델 삭제]로 언제든 제거
2. 사진을 올리면 정렬 결과 목록에 "사진 방향 추천 (AI)" 영역이 생기고 한 장씩 분석 (384×384로 줄인 픽셀만 사용, 컴퓨터 밖으로 안 나감)
3. 누운 사진에 `↺ 왼쪽 90° 92%` 같은 표시. 확신도 85% 미만은 "확인 필요". 표시를 누르면 대상에서 제외
4. [네이버 편집기로 N장 돌리기] → 이번에 올린 사진 컴포넌트(`data-compid`)와 편집기 썸네일(`data-key`)을 짝지어 회전·적용을 자동으로 누름. 콜라주·슬라이드로 올린 경우는 지원하지 않음
- 모델 출처: DuarteBarbosa/deep-image-orientation-detection (MIT). 자세한 내용은 `docs/models/README.md`
- 네이버 편집기 버튼 정보: 프로젝트 문서 `naver-photo-editor-selectors.md`
- 자체 테스트(필름 스캔 39장): 두 모드 모두 39/39, 브라우저 WASM 기준 장당 약 0.5초
