네이버 블로그·카페 사진(파일) 업로드 순서 유지 +회전(AI)

네이버 블로그·카페에 사진·파일을 여러 장 올릴 때 파일명·수정일·촬영일·크기·종류 기준으로 정렬된 순서대로 에디터에 넘겨주는 Chrome 확장 프로그램입니다.

v1.4.0부터는 네이버 카페 글쓰기에서도 똑같이 동작합니다.

v1.3.0부터는 세로로 찍었는데 누워서 올라간 사진을 AI가 찾아, 네이버 에디터의 「사진 편집 → 자르기, 회전」 기능으로 바로 세워 줍니다. AI 분석은 내 컴퓨터 안에서만 이루어지고, 원본 파일은 바뀌지 않습니다.
