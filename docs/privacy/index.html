개인정보처리방침

Chrome 확장 프로그램 「네이버 블로그·카페 사진(파일) 업로드 순서 유지 +회전(AI)」 · 시행일 2026-10-25 (v1.4.0 기준)

네이버 블로그·카페 사진(파일) 업로드 순서 유지 +회전(AI)(이하 “확장 프로그램”)는 사용자의 개인정보를 수집·저장·전송하지 않습니다.

1. 수집하는 개인정보

없습니다. 이름, 이메일, 계정 정보, 방문 기록, 위치 정보 등 어떠한 개인정보도 수집하지 않습니다.

2. 파일 정보의 처리

  • 사용자가 네이버 블로그·카페에 업로드하려고 선택하거나 끌어다 놓은 파일의 이름·크기·수정일·종류와 사진의 촬영일(EXIF, JPEG·HEIC·PNG)을 읽습니다.
  • 이 정보는 파일을 정렬하고, 정렬 결과 목록에 썸네일을 보여주는 목적으로만 사용자의 브라우저 안에서 처리됩니다.
  • 파일 내용과 파일 정보는 외부 서버로 전송되지 않으며, 정렬이 끝난 뒤 따로 보관하지 않습니다.
  • 사진 방향 추천(AI)을 켠 경우에만, 사진을 384×384 크기로 줄인 픽셀을 만들어 확장 프로그램 안의 AI 모델로 방향을 판단합니다. 이 분석은 사용자의 컴퓨터 안에서만 이루어지며, 사진은 외부로 전송되지 않습니다.
  • 사진 회전은 네이버 블로그·카페 에디터의 「사진 편집 → 자르기, 회전」 기능을 사용합니다. 확장 프로그램은 사용자 컴퓨터의 원본 파일을 수정하지 않습니다.

3. 저장하는 정보

  • 정렬 설정(사용 여부, 정렬 기준, 오름차순/내림차순, 알림·결과 목록·썸네일 표시 여부)과 사진 방향 추천(AI) 모드만 Chrome의 chrome.storage.sync에 저장합니다.
  • 사진 방향 추천(AI)을 켜면 AI 모델 파일(약 21~40MB)과 설치 상태를 확장 프로그램 전용 저장 공간(Cache Storage, chrome.storage.local)에 저장합니다. 설정 창의 [모델 삭제]로 언제든 지울 수 있습니다.
  • Chrome 동기화가 켜져 있으면 이 설정값이 사용자의 Google 계정을 통해 다른 기기의 Chrome과 동기화될 수 있습니다. 이 동기화는 Google이 제공하는 기능이며, 개발자는 이 값에 접근할 수 없습니다.

4. 외부 통신 및 제3자 제공

  • 사진 방향 추천(AI)을 켠 경우에만, AI 모델 파일을 taehee33.github.io(이 방침이 게시된 GitHub Pages)에서 한 번 내려받습니다. 이 요청에는 사진이나 개인정보가 포함되지 않습니다. 그 밖에는 외부 서버와 통신하지 않습니다.
  • 원격 코드를 불러오지 않습니다. AI 실행 엔진(onnxruntime-web)은 확장 프로그램 안에 포함되어 있으며, 내려받는 모델 파일은 실행 코드가 아닌 데이터입니다.
  • 분석 도구, 광고, 추적 스크립트를 사용하지 않습니다.
  • 사용자 데이터를 제3자에게 제공하거나 판매하지 않습니다.

5. 권한 사용 목적

  • storage: 위 3항의 설정을 저장하기 위해 사용합니다.
  • offscreen: AI 모델을 화면에 보이지 않는 확장 페이지에서 실행하기 위해 사용합니다.
  • unlimitedStorage: 내려받은 AI 모델 파일을 저장하기 위해 사용합니다.
  • 사이트 접근(blog.naver.com, m.blog.naver.com, cafe.naver.com): 네이버 블로그·카페 글쓰기 화면에서 파일 목록을 정렬하고 회전을 돕기 위해 해당 사이트에서만 동작합니다. 네이버 카페에서는 글쓰기·글 수정 화면에서만 정렬하며, 다른 사이트에서는 동작하지 않습니다.
